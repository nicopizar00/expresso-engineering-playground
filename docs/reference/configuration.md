# Configuration reference

This reference lists 39 unique direct-read first-party configuration keys used by the BFF, web
app, visualizer, local CLI, and performance workflows. A key that appears in
several runtimes counts once. Container and deployment manifests may pass or
override these values; Compose-only inputs are identified separately.

## BFF

The BFF reads its database connection, server settings, order timing, session lifetime, and telemetry settings when it starts. Health reads its version on each request. `DATABASE_URL` is required for database-backed operation.

| Key                           | Default                                                                        | Binding and behavior                                                                                                                                                            | Usage                                                                                                                                                                                                                                      |
| ----------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `DATABASE_URL`                | None in the application; local Compose derives it from the PostgreSQL settings | Required by Prisma. Prisma CLI configuration loads the root environment file when this value is absent or empty; the BFF service does not implement that loader.                | Set the PostgreSQL connection string for BFF database access. An unset or unusable value prevents database startup or Prisma operations.                                                                                                   |
| `PORT`                        | `3001`                                                                         | BFF HTTP listener. Compose supplies `BFF_PORT` as the container's `PORT` but keeps its mapping target and healthcheck at `3001`. Kubernetes keeps the container port at `3001`. | Change the listener port when running the BFF directly. Empty text converts to `0`; invalid text converts to `NaN`. Changing only `BFF_PORT` can break Compose forwarding and healthchecks.                                                |
| `CORS_ORIGIN`                 | `*`                                                                            | BFF CORS origin configuration.                                                                                                                                                  | Set the permitted browser origin. Unset allows any origin; the value is passed to the CORS configuration as supplied.                                                                                                                      |
| `ORDER_COOL_DOWN_SECONDS`     | `300` seconds                                                                  | Parsed at BFF startup. Compose exposes this setting; the Kubernetes BFF deployment sets its own value.                                                                          | Set an integer from 1 through 31536000 without whitespace or leading zeroes. Unset or empty uses the default; other invalid values abort startup.                                                                                          |
| `AUTH_SESSION_TTL_DAYS`       | `30` days                                                                      | Parsed at BFF startup and used to set authentication session lifetime.                                                                                                          | Set an integer from 1 through 365 without whitespace or leading zeroes. Unset or empty uses the default; other invalid values abort startup.                                                                                               |
| `BFF_VERSION`                 | `0.0.0`                                                                        | Read for the BFF health response version on every check.                                                                                                                        | Override the version reported by health checks. Unset reports `0.0.0`; empty stays empty and the value is not validated.                                                                                                                   |
| `NODE_ENV`                    | `development` for the telemetry resource attribute when unset                  | Read by BFF telemetry configuration. Runtime images set `production`.                                                                                                           | Set the telemetry environment label. Unset labels telemetry as development; empty remains empty and no validation is applied.                                                                                                              |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | No application fallback                                                        | Read by BFF telemetry initialization; Compose and Kubernetes set the collector endpoint for the BFF container. The exporter appends `/v1/traces`.                               | Set the OTLP HTTP base endpoint without a trailing slash. If unset or empty, telemetry initialization returns without starting the SDK. No URL validation is applied. Compose fixes its BFF endpoint regardless of the root example value. |
| `npm_package_version`         | `0.0.0`                                                                        | Read as the BFF telemetry service version attribute when present.                                                                                                               | Normally supplied by the package manager. If absent, telemetry uses `0.0.0`; empty remains empty and no validation is applied.                                                                                                             |

## Web

The web app uses public variables in the browser bundle and internal URLs in the server-side proxy. Public values are baked into the web build; changing their container environment after the build does not replace the embedded values. Compose and Kubernetes supply rewrite targets during image build. Compose also supplies runtime targets for development mode. Server-side API calls read the BFF target at call time.

| Key                             | Default                                                              | Binding and behavior                                                                                                                                                   | Usage                                                                                                                                                                                                                                              |
| ------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BFF_INTERNAL_URL`              | `http://localhost:3001`                                              | Next.js rewrite destination at production build or development server start; server-side API fallback at call time. One trailing slash is removed.                     | Set the BFF's server-reachable URL. Compose uses `http://bff:3001`; Kubernetes builds with the in-cluster service address. Unset or empty falls back to localhost; whitespace is not trimmed and URLs are not validated.                           |
| `VISUALIZER_INTERNAL_URL`       | `http://localhost:3002`                                              | Next.js visualizer rewrite destination at production build or development server start. One trailing slash is removed.                                                 | Set the visualizer's server-reachable URL. Compose uses `http://visualizer-3d:80`; Kubernetes builds with the in-cluster service address. Unset or empty falls back to localhost; URLs are not validated.                                          |
| `NEXT_PUBLIC_API_BASE_URL`      | Empty, which selects the same-origin `/api/bff` proxy                | Public web API override, read by the API client. Build-time value.                                                                                                     | Set only when the browser should call a BFF URL directly. The value is trimmed; a whitespace-only value behaves as unset. No URL validation is applied.                                                                                            |
| `NEXT_PUBLIC_DEMO_MODE`         | Unset, treated as false                                              | Public web API selection flag. Build-time value.                                                                                                                       | Set exactly to `true` to enable demo mode. Other values, including `TRUE`, are false.                                                                                                                                                              |
| `NEXT_PUBLIC_VISUALIZER_URL`    | Empty in the component; Compose and Kubernetes set a host-facing URL | Public link to open the visualizer outside its embedded route. Build-time value.                                                                                       | Set the browser-reachable visualizer URL. Compose defaults to `http://localhost:3002`; Kubernetes builds it from `VIZ_PORT`. Unset or empty opens the embedded URL in a new tab, including `?embed=1` in embed mode. No URL validation is applied. |
| `NEXT_PUBLIC_PRISMA_STUDIO_URL` | Unset                                                                | Public URL used for the optional Studio link. Build-time value.                                                                                                        | Set a browser-reachable Studio URL to show the admin link. Unset or empty hides it; nonempty values are not validated. Compose passes an empty value when unset.                                                                                   |
| `PORT`                          | `3000` in the container                                              | Next.js server listener. Compose supplies `WEB_PORT` as this value but keeps its mapping target and healthcheck at `3000`. The Kubernetes container listens on `3000`. | Change the listener when running the web server directly. Changing only `WEB_PORT` can break Compose forwarding and healthchecks.                                                                                                                  |

## Visualizer

The visualizer's container entrypoint writes its API base URL into the served runtime configuration. This makes the API destination a container-start setting rather than a value embedded in the web app build.

| Key                | Default                 | Binding and behavior                                                                                                                         | Usage                                                                                                                                                                   |
| ------------------ | ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `VIZ_API_BASE_URL` | `http://localhost:3001` | Read by the visualizer container entrypoint and written into its runtime configuration. Compose sets the default to the host-facing BFF URL. | Set the URL the visualizer browser code uses for visualization requests and event streaming. An unset or empty value selects the default. No URL validation is applied. |

## Local CLI

The local CLI loads the root `.env` file, bootstrapping it from `.env.example` when necessary. Existing process environment values take precedence, including empty values. Port values are read once when the CLI modules load; empty or noninteger text falls back to the default. Integer parsing permits whitespace, signs, zero, and out-of-range numbers without validating port bounds. Compose interpolation is separate and does not share this fallback for invalid text.

| Key                 | Default                          | Binding and behavior                                                                             | Usage                                                                                                                                 |
| ------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| `POSTGRES_USER`     | `playground`                     | Compose PostgreSQL user and input to the CLI's generated database URLs.                          | Set the local PostgreSQL user. Unset uses the default; empty is preserved in CLI-generated URLs but defaults in Compose.              |
| `POSTGRES_PASSWORD` | `playground`                     | Compose PostgreSQL password and input to the CLI's generated database URLs.                      | Set the local PostgreSQL password. Unset uses the default; empty is preserved in CLI-generated URLs but defaults in Compose.          |
| `POSTGRES_DB`       | `mini_commerce_playground`       | Compose database name and input to the CLI's generated database URLs.                            | Set the local PostgreSQL database name. Unset uses the default; empty is preserved in CLI-generated URLs but defaults in Compose.     |
| `BFF_PORT`          | `3001`                           | Host port used by Compose, CLI readiness checks, local URLs, and port forwarding.                | Set a free numeric host port. Invalid or empty values fall back to `3001`.                                                            |
| `WEB_PORT`          | `3000`                           | Host port used by Compose, CLI readiness checks, local URLs, and port forwarding.                | Set a free numeric host port. Invalid or empty values fall back to `3000`.                                                            |
| `VIZ_PORT`          | `3002`                           | Host port used by Compose, CLI URLs, port forwarding, and the web image's public visualizer URL. | Set a free numeric host port and keep the web image's build-time visualizer URL aligned. Invalid or empty values fall back to `3002`. |
| `STUDIO_PORT`       | `5555`                           | Host port for optional Prisma Studio in Compose.                                                 | Set a free numeric host port. Invalid or empty values fall back to `5555`.                                                            |
| `GRAFANA_PORT`      | `3030`                           | Host port for the Compose Grafana service.                                                       | Set a free numeric host port. Invalid or empty values fall back to `3030`.                                                            |
| `PROMETHEUS_PORT`   | `9090`                           | Host port for the Compose Prometheus service.                                                    | Set a free numeric host port. Invalid or empty values fall back to `9090`.                                                            |
| `TEMPO_PORT`        | `3200`                           | Host port for the Compose Tempo service.                                                         | Set a free numeric host port. Invalid or empty values fall back to `3200`.                                                            |
| `PUNCH_VENV_DIR`    | `<repository>/.cache/punch-venv` | Virtual environment directory selected by the Punch launcher.                                    | Set an alternate virtual environment path. If unset or empty, the launcher uses the repository cache path.                            |
| `NO_COLOR`          | Unset                            | CLI ANSI output control.                                                                         | Set to any nonempty value to disable color. Unset or empty leaves color enabled when supported.                                       |

## Performance wrapper and scenarios

The performance CLI constructs the execution environment from the host environment, then supplies a workflow's declared forwarded values to its container. The k6 scripts also read scenario inputs directly. Dataset path variables are populated by the workflow data contract when the required dataset is mounted; they are not ordinary operator overrides.

| Key                       | Default                                                                                                                                          | Binding and behavior                                                                                             | Usage                                                                                                                                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `BASE_URL`                | Local CLI: `http://host.docker.internal:<BFF_PORT>` for HTTP workflows and the web port for browser purchase; direct k6: `http://localhost:3001` | Target URL forwarded to applicable k6 workflows.                                                                 | Set the reachable target URL. The local workflow CLI honors a nonempty inherited value before its workflow default; an explicit extra environment value can override it. No URL validation is applied. |
| `K6_ENV`                  | `local`                                                                                                                                          | Read by shared k6 configuration.                                                                                 | Label the k6 environment. Unset or empty becomes `local`; no validation is applied.                                                                                                                    |
| `SCENARIO`                | Unset                                                                                                                                            | Legacy shell wrapper selector. A nonempty value replaces the script argument; remaining arguments are preserved. | Choose `http-purchase`, `browser-purchase`, `http-cart`, `browser-cart`, or `http-orders`. Unknown nonempty values fail; unset or empty forwards arguments untouched.                                  |
| `K6_SCRIPTS_DIR`          | `/scripts/scenarios`                                                                                                                             | Root directory used by the shell wrapper to resolve scenario scripts.                                            | Override the scenario directory in a custom container layout. Unset or empty uses `/scripts/scenarios`.                                                                                                |
| `USERS`                   | All built-in demo users                                                                                                                          | Forwarded for the registered-purchase workflow and parsed by that scenario.                                      | Provide comma-separated usernames. Entries are trimmed and lowercased without account validation. Empty entries are discarded; if no names remain, all demo users are used.                            |
| `EXPECT_TEMPERATURE`      | `auto`                                                                                                                                           | Forwarded to the order-status scenario and normalized to lowercase.                                              | Choose `auto`, `hot`, or `cold`. Unset or empty uses the default; any other value fails initialization. Whitespace is not trimmed.                                                                     |
| `ORDER_COOL_DOWN_SECONDS` | `300` seconds in the scenario                                                                                                                    | Forwarded to the order-status scenario; it must match the BFF setting for meaningful checks.                     | The scenario converts this to milliseconds; zero, empty, missing, or nonnumeric values fall back to `300`. Unlike the BFF, the scenario does not reject negative or fractional numbers.                |
| `DEMO_PASSWORD`           | `espresso-demo`                                                                                                                                  | Forwarded to the login workflow and used to authenticate its demo accounts.                                      | Set the shared password for the demo users. Unset or empty uses the default.                                                                                                                           |
| `DATA_ORDERS_CSV`         | No scenario fallback                                                                                                                             | Workflow-provided path for the required orders dataset in the order-status scenario.                             | Supplied by the workflow data mount. Missing or unreadable input causes k6 initialization to fail.                                                                                                     |
| `DATA_CARTS_CSV`          | No scenario fallback                                                                                                                             | Workflow-provided path for the required carts dataset in the orders scenario.                                    | Supplied by the workflow data mount. Missing or unreadable input causes k6 initialization to fail.                                                                                                     |
| `DATA_OWNED_ORDERS_CSV`   | Unset; the login scenario then uses built-in demo users                                                                                          | Optional workflow-provided owned-orders dataset path.                                                            | If unset or empty, the scenario uses all built-in demo users. A supplied unreadable path fails initialization; a readable file supplies its nonempty username entries.                                 |
| `DATA_AUTH_TOKENS_CSV`    | No scenario fallback                                                                                                                             | Workflow-provided path for the required auth-token dataset in the hot-status scenario.                           | Supplied by the workflow data mount. Missing or unreadable input causes k6 initialization to fail.                                                                                                     |

## Deployment-only keys

Deployment configuration can override the first-party inputs above. Compose sets the database URL, BFF listener port, order cooling interval, collector endpoint, web proxy URLs, public web URLs, visualizer API URL, and host port mappings. Kubernetes sets database credentials and the BFF cooling interval in its manifests. Its web image bakes internal proxy URLs and the public visualizer URL at build time. These deployment values are described with their owning runtime keys above. The following Compose interpolation values are outside the direct-read inventory.

| Key                      | Default               | Binding and behavior                                                                                                                                     | Usage                                                                             |
| ------------------------ | --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `K6_OTEL_ENDPOINT`       | `otel-collector:4317` | Compose-only interpolation value mapped to `K6_OTEL_GRPC_EXPORTER_ENDPOINT` for the `k6-otel` service. The destination key is consumed by k6's exporter. | Override the collector's gRPC endpoint for the OTLP-enabled runner.               |
| `GRAFANA_ADMIN_USER`     | `admin`               | Compose-only input passed to Grafana's `GF_SECURITY_ADMIN_USER`.                                                                                         | Set the Grafana admin username. This is not read by first-party application code. |
| `GRAFANA_ADMIN_PASSWORD` | `admin`               | Compose-only input passed to Grafana's `GF_SECURITY_ADMIN_PASSWORD`.                                                                                     | Set the Grafana admin password. This is not read by first-party application code. |

## Example-only input

| Key             | Default | Binding and behavior                                                       | Usage                                                                                                                                   |
| --------------- | ------- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `REPORT_OUTPUT` | None    | Appears only in an example and is not consumed by maintained runtime code. | Do not use it to select a report destination. The local orchestrator writes reports under its configured performance reports directory. |
